# RSVP Reader Android

Android native RSVP reading tool focused on paced reading with persistent sentence context.

- Kotlin + Jetpack Compose
- TXT, text-layer PDF, EPUB import
- Per-document persistent reading position
- Context + RSVP synchronized highlighting
- WPM and punctuation delay controls
- Full-text navigation
- Global reader appearance settings

Build with:

`gradle :app:assembleDebug`

Debug APK:

`app/build/outputs/apk/debug/app-debug.apk`
