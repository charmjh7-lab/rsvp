# 외부 UX·접근성·플랫폼 품질 기준

적용 전 최신 원문을 확인하고 공식 플랫폼 요구, 전문가 휴리스틱, 앱별 품질 계약을 구분한다.

Google Android 품질: https://developer.android.com/docs/quality-guidelines/core-app-quality — 다크모드, 화면 상태 복귀, 시스템 내비게이션과 기본 사용성.
Material Dialog: https://developer.android.com/develop/ui/compose/components/dialog — 확인·취소·닫기·레이아웃.
Material 3: https://developer.android.com/develop/ui/compose/designsystems/material3 — 디자인 역할과 테마.
Android 접근성: https://developer.android.com/design/ui/mobile/guides/foundations/accessibility 및 https://developer.android.com/guide/topics/ui/accessibility/apps — 48dp 터치 영역 권장, 조작의 발견성과 대체 경로.
Android 창 크기: https://developer.android.com/develop/adaptive-apps/guides/use-window-size-classes — 실제 창 크기와 안전 영역 대응.
WCAG 2.2: https://www.w3.org/TR/WCAG22/ — 웹·웹뷰의 대비, 포커스·접근 가능한 조작.
NN/g 휴리스틱: https://www.nngroup.com/articles/ten-usability-heuristics/ — 시스템 상태·사용자 통제·오류 예방·회복.

모든 화면에 일률적인 CRUD·고정 footer가 공식 의무라는 식으로 단정하지 않는다. 앱의 실제 사용 목적에 맞추어 적용한다.
