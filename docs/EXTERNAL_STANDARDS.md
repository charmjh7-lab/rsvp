# 외부 UX·접근성·플랫폼 품질 기준

Google Android 핵심 앱 품질: https://developer.android.com/docs/quality-guidelines/core-app-quality
Material 대화상자: https://developer.android.com/develop/ui/compose/components/dialog
Material Design 3: https://developer.android.com/develop/ui/compose/designsystems/material3
Android 접근성: https://developer.android.com/design/ui/mobile/guides/foundations/accessibility
Android 창 크기·폴더블: https://developer.android.com/develop/adaptive-apps/guides/use-window-size-classes
WCAG 2.2 (웹 UI): https://www.w3.org/TR/WCAG22/
Nielsen Norman Group 사용성 휴리스틱: https://www.nngroup.com/articles/ten-usability-heuristics/

실제 구현 시 최신 원문을 확인하고 플랫폼 기준과 제품별 UX 계약을 구분한다. 필수 조작 접근성, 상태 가시성, 밝음/어두움 대비, 취소·복귀를 고려한다. 모든 앱에 동일한 CRUD·고정 모달을 강요하지 않는다.
