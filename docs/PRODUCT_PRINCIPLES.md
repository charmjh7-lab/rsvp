# RSVP Reader — 제품 및 설계 원칙

이 앱의 목적은 무조건적인 속독이 아니라 한 토큰씩 놓치지 않고 읽도록 돕는 독서 경험이다. 읽기 속도는 사용자가 조절하며, 이해와 문맥 보존을 우선한다. 일반적인 RSVP 구현으로 임의로 되돌리지 않는다.

읽기 위치의 권위는 `globalTokenIndex`다. 토큰의 원문 범위, 문장 문맥, 전체 글 화면, TTS 동기화, 탐색과 저장·복원의 위치 의미가 어긋나지 않게 유지한다. TXT·PDF·EPUB 가져오기, 문서별 상태와 기존 서재 데이터의 호환성을 보호한다.

읽기 모드·표시 규칙·조작 방법을 변경할 때 실제 읽기 흐름과 인지 부담을 검토한다. 별도 Eye Reader는 `development/eye-movement`에서 별도 앱 ID·데이터·서명을 유지하므로 원본 앱과 혼동하여 통합하거나 덮어쓰지 않는다.

기준: `README.md`, 텍스트 처리 및 읽기 위치 모델, 관련 테스트, `.github/workflows/`. 실제 독서 이해 향상을 검증하지 않고 효과가 입증되었다고 주장하지 않는다.
