# Eye Reader — UX 실사용 계약

## 사용 목적

원래 RSVP Reader의 서재·자료 불러오기·읽기 위치를 유지한 채 별도 Android 앱에서 시선 이동에 따른 글자 제시 방식의 사용성을 실험한다. 기존 RSVP Reader와 다른 applicationId·아이콘·저장소·개발 서명을 유지하며 원본 앱을 덮어쓰지 않는다. 눈의 이동과 이해 향상 효과는 확인된 연구 범위를 넘어 단정하지 않는다.

## 주요 화면과 작업

읽기 화면에서는 좌우 교대/자리채움 제시 모드, 표시 단위(단어/결합 문자), 앞부분 유지 옵션, 현재 글자 위치 안내, 재생·일시정지·이전·다음, 속도 변경의 발견성과 조작 일관성이 중요하다. 모드 버튼의 짧게 누르기와 길게 누르기는 다른 동작이어야 하고, 설정·취소·닫기는 작은 화면·키보드·긴 문장에서 접근 가능해야 한다. 모드 변경 중 현재 읽기 위치를 잃거나 읽기 세션이 뜻하지 않게 초기화되지 않게 한다.

## 수용 시나리오

긴 문장 줄바꿈, 화면 높이 변경, 단어/글자 선택·TTS 동기화, 고속 재생·일시정지·모드 재전환에서 위치 표시가 원문과 맞는지 확인한다. 화면 재생성 및 최근 앱 복귀 뒤 저장된 토큰 위치와 글자 커서 정책이 일치해야 한다. 서재에서 이름 변경·삭제·복원 등 기존 작업이 사라지지 않으며 다크모드·큰 글자·작은 화면에도 조작이 가려지지 않는다. 빈 문서·미지원 PDF에서 진행 불가 이유와 돌아가는 경로를 명확히 한다.

기준은 해당 브랜치의 `README.md`, `docs/PRODUCT_PRINCIPLES.md` 및 실제 읽기 위치·표시 로직이다.


## 이 문서의 변경 권한과 근거

`CHANGE_SCOPE_POLICY.md`에 따른다. 현재 UX 문서는 사용자 요청·승인이 없는 상태에서 임의 디자인 변경을 허가하지 않는다. 사용자가 확인한 결정, 현재 코드의 관찰 사실, AI의 미승인 제안, 미결정 사항을 구분한다. UI를 먼저 변경한 뒤 여기나 테스트에 정답으로 기록하는 일을 금지한다.
